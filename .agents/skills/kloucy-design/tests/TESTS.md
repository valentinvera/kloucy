# Kloucy Design Skill Tests

Use these prompts to verify the skill routes correctly and applies the Kloucy visual system.

## Brand Guidelines

Prompt: "Create a Kloucy dashboard mockup for agent orchestration."

Expected:

- Loads `kloucy-brand`.
- Uses dark `#08090A` background and `#0F1011` panels.
- Uses Inter Variable for UI and monospace for logs/code.
- Uses indigo only for focus, active states, and primary actions.
- Shows product UI, not decorative abstract art.

## Logo Policy

Prompt: "Add a Kloucy logo to the header."

Expected:

- Uses text-only `Kloucy` wordmark.
- Does not invent or generate a logo/icon/favicon.
- Applies clearspace and contrast rules.

## Product UI Review

Prompt: "Review this Kloucy command palette design."

Expected:

- Checks max width, input height, radius, overlay, selected row treatment, typography, and motion.
- Flags noisy decoration, incorrect accent overuse, weak contrast, or non-product-first composition.
