## The API exits on startup

Environment validation runs before the server starts. Check `apps/api/.env`:

- `BETTER_AUTH_SECRET` must be at least 32 characters.
- `BETTER_AUTH_URL` and `DATABASE_URL` must be valid.
- `PORT` must be a positive integer.

## "Failed to start server. Is port 4040 in use?"

Another process is already listening. Stop it, or change `PORT` and point the desktop at the new port with `KLOUCY_API_URL`.

## Sign-in fails with an origin error

Add the browser origin to `CORS_ORIGIN` in `apps/api/.env` and restart the API. The desktop app sends no origin, so it is unaffected.

## Type checking cannot find `routeTree.gen.ts`

The file is generated by the Vite router plugin and is not committed. Run the app once (`bun run dev:docs`) or build it, and the file appears.

## Mobile type checks complain about `className`

`uniwind-env.d.ts` and `expo-env.d.ts` are generated and not committed. In `apps/mobile`, `bun run check-types` runs `bun run generate` first, which recreates both.

## A new tRPC procedure returns "No procedure found"

The API consumes the built `@kloucy/trpc` package. Rebuild it, then restart the API:

```bash
bunx turbo run build --filter=@kloucy/trpc
```

## The desktop cannot reach the API

`KLOUCY_API_URL` defaults to `http://localhost:3001`. Point it at your API, for example `http://localhost:4040`.

## Database errors

Confirm `DATABASE_URL` is reachable and that migrations have been applied:

```bash
cd packages/db
bun run db:migrate
```
