The desktop app is a GPUI application written in Rust. It talks to the Kloucy API and starts agents on your machine.

## Build

```bash
cd apps/desktop
cargo build --release
```

The binary lands at `apps/desktop/target/release/kloucy-desktop`.

## Run

```bash
KLOUCY_API_URL=http://localhost:4040 ./target/release/kloucy-desktop
```

<Callout type="warn" title="API URL">
`KLOUCY_API_URL` defaults to `http://localhost:3001`. If your API listens elsewhere (the local setup uses `4040`), set it explicitly.
</Callout>

## Sign in

Use the same account as the web app. Create it once through the API or the web sign-up screen, then sign in from the desktop.

## What you get

- **Home** is the composer: write what you want done, pick the agent that should get it, and it is captured into the Inbox for that workspace. The same row shows the checkout's git branch, and the chips above switch workspace and account.
- **Workspaces** create a workspace and record its intake: project type, package manager, runtime, safe commands, ignored paths, safety mode and whether mobile may supervise it. **Detect project** reads the workspace directory names and fills the profile in, suggesting safe commands and ignored paths for that ecosystem.
- **Agents** register agents by hand or detect installed CLIs on your `PATH`.
- **Inbox** captures tasks; **Sessions** run them and stream logs. Starting a session is an explicit action, and a guarded workspace refuses a command that is not in its safe commands.
- **Reviews** approve changes, reject them with a reason, and record follow-up conditions.
- **Readiness** and **Weekly review** summarize progress over time. The weekly review is derived from stored activity: what shipped, what is blocked, what was rejected, risky patterns and next actions.
- **Pairing** shows a QR code for the mobile app.
- **Settings** correct workspace data, set the default agent, and archive a workspace.

## Command palette

Press `cmd-k`, or `ctrl-k` away from macOS, to open the palette from anywhere in the app. Type to filter, then pick a command:

- jump to any section
- start a new workspace
- register an agent
- detect the agents installed on your `PATH`
- create a new pairing code

Press the shortcut again, press escape, or click outside the palette to close it.
